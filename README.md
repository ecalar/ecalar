## 🧠 Cómo trabajo

1.  **Analizo** el problema y dibujo el flujo de la aplicación.
2.  **Diseño** la base de datos, el diagrama de clases y elijo los patrones (MVC, hexagonal...).
3.  **Desarrollo** el núcleo primero, luego las funcionalidades, con commits pequeños.
4.  **Pruebo y pulo** la interfaz para que sea tan funcional como visual.
